# Experiment 2 — Spatially Non-uniform Visual Feature Changes

真实 Senna Vision Tower 特征：500/500 对，10 个 scene，288000 个位置比较；失败 0 对。

## 特征提取与布局核验

- 模型：`llava.senna.senna_llava_llama.SennaLlavaLlamaForCausalLM`；原始 `load_senna_pretrained_model` 加载。
- 调用：`Senna.prepare_inputs_labels_for_multimodal → Senna.encode_images → get_vision_tower()`；Projector 和 Image Adapter 原样执行，省略后续 LLM 生成。
- 预处理复用 `senna_qa_utils.load_images/process_images`，顺序为 CAM_FRONT, CAM_FRONT_LEFT, CAM_FRONT_RIGHT, CAM_BACK_LEFT, CAM_BACK_RIGHT, CAM_BACK。
- 原始输入 `[1, 6, 3, 336, 336]`，Tower `[6, 576, 1024]`；每摄像头 576 个 Patch Token × 1024 维，网格 24×24。
- Projector 实测首个输出 `[1, 576, 4096]`；Image Adapter `[1, 128, 4096]`；两者各执行六次。
- 原始 CLIP 577 个 Token；CLS 由 Tower 移除：True；分析额外移除 CLS：False。
- Senna 选用 `hidden_states[-2]`，实测索引 23 / 25 个 hidden states。这里的最终输出指 **Senna 实际消费的 Tower 输出**，不将倒数第二层标记成 CLIP 最后一层。
- 与原始生成 helper 的六摄像头 Tower 特征逐元素完全相等：True；预处理输入 SHA256 相等：True。
- 直接读取 E1 `temporal_pairs.csv`；同 scene、同 camera、同位置配对。其他五路仅按 manifest 中最近曝光补齐原始六路输入，允许的偏差和每对六路时间偏移均已记录。
- 空间位置对应经过 padding/resize 后的模型输入；包括模型实际看到的 padding 区域。未进行物理对象运动补偿。

## 空间非均匀性与解释边界

总体 Gini = 0.5938 [0.5770, 0.6113]；Top10% 贡献 = 0.3457 [0.3181, 0.3773]；Top20% 贡献 = 0.5782 [0.5554, 0.6034]。
Top-K 使用向上取整：10% 选 58 个，20% 选 116 个；应与实际 k/N 的均匀基线比较。零总漂移的 Gini 和贡献率定义为 0。
Gini 和 Top-K 描述变化幅度的非均匀性，不能单独证明高漂移位置在空间上连续成团。热力图、稳定位置图和 3×3 区域统计补充位置证据；不把少量高漂移 Token 自动描述为贡献了“大部分”变化。
应结合全部阈值和时间间隔判断证据，结果不预设稳定 Token 必然占多数。本实验不对特征稳定的原因（静态物体、padding、注意力混合等）作因果归因。

## 真实视觉计算成本

- 来源：`experiment1`，300 个测量；六视角完整 Vision Tower Mean 56.270 ms，P95 56.912 ms。
- 该成本已经包含六个摄像头，不能再乘六。复用判据或补测信息见 `latency_provenance.json`。
- 稳定 Token 比例仅表示理论复用机会，不能等同于 FLOPs 节省或真实时延收益；本实验没有实现缓存、增量执行、跳窗或 Token Pruning，也没有测量加速比。

## 完整性、统计与复现

- scene Bootstrap 重采样 2000 次，随机种子 42；少于两个 scene 不输出 CI。曲线 CI 是逐点区间。
- 所有失败/缺失样本见 `feature_issues.json` 和 samples CSV 的 failed 行；零范数/非有限特征导致整对拒绝。
- `pair_results/` 仅存 CPU 距离数组和配对元数据，支持逐对原子断点恢复；未保存完整视觉特征。
- 原始索引、代码、依赖、权重文件大小/mtime 和逐对结果 SHA256 记录在 metadata 中；改变配置/代码需新目录或显式 overwrite（旧测量归档）。
- 配对选择不依赖图像内容或测得漂移。完整命令：

